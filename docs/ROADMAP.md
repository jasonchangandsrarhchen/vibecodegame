# Turn-Based Reboot — Development Roadmap

## Milestone 0 — Design reset
- [x] Preserve the previous real-time prototype on main.
- [x] Create isolated turn-based development branch.
- [x] Establish squad tactics design baseline.

## Milestone 1 — Tactical combat prototype
- [x] Grid battlefield and unit selection.
- [x] Movement with action point costs.
- [x] Weapon range and line of sight.
- [x] Three operative archetypes and signature skills.
- [x] Enemy intent previews and enemy phase.
- [x] Cover, obstacles and combat feedback.
- [x] Win/lose state and restart loop.

## Milestone 2 — Tactical depth
- [ ] Fourth operative and squad composition choices.
- [ ] More enemy archetypes and coordinated behaviors.
- [ ] Status effects and elemental interactions.
- [ ] Overwatch, suppression, flanking and destructible cover.
- [ ] Boss arenas with phases and telegraphed attacks.

## Milestone 3 — Roguelite structure
- [ ] Branching route map and room types.
- [ ] Rewards, modules, gear and consumables.
- [ ] Extraction and defeat settlement.
- [ ] Safehouse and permanent progression.
- [ ] Difficulty tiers and modifiers.

## Milestone 4 — Content and production
- [ ] Four regions, 8+ bosses and expanded enemy roster.
- [ ] Narrative events, logs and multiple endings.
- [ ] Audio/visual asset pipeline and animations.
- [ ] Accessibility, remappable controls and gamepad support.
- [ ] Save versioning, performance and balance pass.

## Quality rule
Do not mark a feature complete until it is demonstrable in the playable build. Every milestone must leave the game playable.
